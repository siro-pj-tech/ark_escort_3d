# 🚀 ARK ESCORT 3D（リフレクション縦スクロールSTG）

移民船団『アーク・ノヴァ』と4隻の護衛輸送船を海賊艦隊の襲撃から守り抜き、新天地『エデン・テラ』へ送り届ける**3Dリフレクション防衛シューティングゲーム**です。  
指1本（またはマウス操作）の**「タップ（範囲ボム）」**と**「スライド（3回反射レーザー）」**を使い分け、敵の装甲属性や出現位置に応じた戦術で全4ステージの突破を目指します。

* **現在のバージョン**: v5.5
* **対応環境**: スマートフォン（縦画面最適化） / PCブラウザ（レスポンシブ対応）
  * どの画面サイズでも 9:16 の比率を保って表示します（縦長スマホでは上下に余白が入ります）。
  * 高解像度ディスプレイ（Retina 等）では解像度に合わせてくっきり描画します。
* **技術構成**: HTML5 Canvas + Three.js (WebGL / GLTFLoader) + Web Audio API

---

## 🎮 ゲームモード（タイトル画面）

1. **通常スタート**  
   Stage 1〜4までの本編ミッションに挑戦します。Stage 1冒頭の船団見送り演出から始まり、最終ステージ（FINAL STAGE）の海賊王旗艦撃破後に、生き残った船団とともに新天地『エデン・テラ』へ到着するエンディング（ALL CLEAR）を迎えます。
2. **チュートリアル**  
   範囲ボム・反射レーザー・八方ミサイルの基本操作を3ステップで実践練習できるガイドモードです（チュートリアル中はボムを無制限に使えます）。
3. **3Dギャラリー**  
   登場する移民船団・海賊機・小惑星・大型ボス戦艦の全9種類の3Dモデルを、上下左右360°ドラッグ回転＆右端のズームスライダー（`0.50x`〜`3.00x`）で自由に鑑賞できます。

## 🕹️ 操作方法と兵装システム

| アクション | 操作方法 | 効果・特徴 |
| :--- | :--- | :--- |
| **範囲ボム爆撃** | **射程ライン（オレンジの弧）の内側をタップ** | 指定地点に余韻爆風を伴う範囲爆撃を行います。敵弾もかき消せます。<br>・射程は**母船を中心とした扇形**で、弧の外側（暗く斜線の入ったエリア）は射程外です。<br>・射程内に入ったボムが効く敵には**オレンジの照準（ロックオン）マーク**が付きます。<br>・**最大3発のストック制**。1発あたり**1.5秒**で自動回復し、**レーザーで敵を撃破すると回復が早まります**。<br>・射程外をタップすると × 印と射程ラインへの誘導線が表示されます。 |
| **リフレクション・レーザー** | **画面をスライド（ドラッグ）** | スライド方向へ**画面端や防衛シールドを最大3回反射**する高出力レーザーを発射します。回数制限はなく、射程外にいる画面上部の敵や対爆装甲の迎撃に有効です。 |
| **イージスバリア展開** | **左下 `⬡` スロットをタップ** | 敵を一定数撃破（ボス戦ではボスへ**8回命中**）してゲージが100%（虹色発光）になると発動可能。一定時間すべての敵弾・体当たり・レーザーを完全遮断します（緑→橙→赤の順に減衰）。バリア展開中も次のゲージは溜まるので、切れる前に張り直せます。 |
| **アーク・ノヴァ主力ビーム砲** | **右下 `⚡` スロットをタップ** | **ボス戦限定**。10秒で100%チャージされると、旗艦から極太の貫通プラズマビームを照射してボスに大ダメージを与えます。 |
| **八方ミサイル** | **出現する `★` マークをタップ** | 敵撃破時（およびステージ3のボス戦中）に出現してゆっくり降下する `★` マークをタップすると、その場から8方向へ直線ミサイルを一斉発射します。射程の制限はありません。 |

> **Tip:** `⬡` / `⚡` ボタンの周囲をタップしてもボムは発動しません（誤爆防止）。

## 📊 画面表示（HUD）

* **左上**: 現在のステージ（Stage 4 は `FINAL STAGE` と表示）
* **右上**: スコア
* **上部中央（ボス戦）**: ボス名・HPバー・弱点（登場時に表示）
* **下部**: `FLEET`（船団HPバー。目盛りは輸送船が1隻沈むライン）と `BOMB`（ボム残数と回復の進み具合）
* **5本の青いライン**: 防衛シールド（1本＝耐久20%）

## 🛡️ 敵の装甲属性と相性

敵機は機体カラー（装甲属性）によって有効な攻撃が異なります。

* **🔴 RED（通常装甲）**: 範囲ボム・反射レーザーのどちらも有効。
* **🟣 PURPLE（対爆結晶）**: **範囲ボム無効**（ロックオンマークも付きません）。反射レーザーで撃破可能。
* **🟡 YELLOW（対光学鏡面）**: **反射レーザー無効（弾かれる）**。射程ラインの内側まで引きつけて範囲ボムで撃破可能。
* **🔵 BLUE（重装甲）**: 範囲ボム・反射レーザー両対応の高耐久機。

## 👾 ステージ構成＆ボス

* **Stage 1 〜 Stage 3**: 30秒間の防衛ウェーブ突破後、`WARNING` 警報とともにボス戦艦 **『ドレッド・クルーザー』** が出現。
  * **MK-1（Stage 1）**: 弱点なし。すべての攻撃が有効。
  * **MK-2（Stage 2）**: 対爆装甲。範囲ボムがほぼ効かないため、レーザーで攻撃。
  * **MK-3（Stage 3）**: シールド装備。ボム・レーザーがほぼ効かないため、ボス戦中に出現する `★` の八方ミサイルと母船の主力ビーム砲で攻撃。
* **Stage 4（FINAL STAGE）**: 結晶小惑星を含む猛攻を凌いだ後、海賊王旗艦 **『ガレオン・レヴィアタン』** との決戦に突入します（斜め4方向ランダム反射レーザー3連射＋主力プラズマ砲を使用。全攻撃の効果が半減するため、主力ビーム砲が鍵）。
* **エンディング**: 新天地『エデン・テラ』に到着すると、`ALL CLEAR` の表示とファンファーレとともに生存船団数と最終スコアが表示されます。

## 📁 ファイル構成（GitHub Pages 公開用）

```text
ark-escort-3d/
├── index.html          # ゲーム本体
├── bgm.dat             # 通常ステージ用BGM（暗号化データ）
├── bgm2.dat            # ボス戦用BGM（暗号化データ）
├── models/             # 外部3Dモデル（GLB形式・未配置時は内蔵3Dモデルで自動動作）
│   ├── ark_nova.glb
│   ├── hope_carrier.glb
│   ├── enemy_delta.glb
│   ├── enemy_glider.glb
│   ├── enemy_gunship.glb
│   ├── enemy_dart.glb
│   ├── asteroid.glb
│   ├── boss_cruiser.glb
│   └── boss_leviathan.glb
└── README.md           # 本説明書
```

> **Note:**
> * `bgm.dat` / `bgm2.dat` および `models/*.glb` が配置されていない環境でも、内蔵のプロシージャル3DモデルとWeb Audio API効果音のみでそのまま動作します。
> * BGM と 3D モデルの読み込みには Web サーバーが必要です（GitHub Pages ならそのまま動作します。HTML をダブルクリックで開いた場合は内蔵モデル・効果音のみで動作します）。
> * Three.js は CDN（unpkg）から読み込むため、プレイにはインターネット接続が必要です。
